# IA3 SimWorld Scale Architecture

This folder documents the target architecture for a scalable Kubernetes-based IA3 platform.

It is written for the long-term vision: loosely coupled services, batch-friendly profile imports, and a stable realtime simulation core.

## Files

- `target-architecture.md` — service boundaries and system shape
- `coupling-and-timing.md` — what should interact in realtime vs batch
- `deployment-and-scaling.md` — Kubernetes/cloud deployment model
- `mvp-to-platform.md` — migration path from the current skeleton
